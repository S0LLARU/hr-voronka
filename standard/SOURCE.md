# Копия стандарта дизайна

Это копия репозитория [S0LLARU/standart_for_product_design](https://github.com/S0LLARU/standart_for_product_design) на коммите `38385ef` (стандарт 3.0.0, руководство «Как мы делаем экраны»). Она лежит здесь, чтобы работать по стандарту без второго репозитория.

Здесь стандарт только читают. Если что-то в нём нужно поменять, это делают в основном репозитории, а сюда потом копируют заново. Интерактивный чек-лист для проверки человеком опубликован отдельно, ссылка — в `README.md`.
